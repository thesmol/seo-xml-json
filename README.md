# seo-xml-json — задание №7

Здесь собраны работы по дисциплине «SEO — оптимизация портальных решений».

## Публикации и исходники

- №7: [GitHub Pages](https://thesmol.github.io/seo-xml-json/task-07/), код в `task-07/`.

В каждой папке находится отдельное задание со всеми нужными файлами.

## Локальный запуск

```sh
npm ci
npm run dev
```

Откройте адрес, показанный Vite (обычно `http://127.0.0.1:5173/`). Для AJAX и XML используйте HTTP, а не `file://`.

Для сборки и проверки статической публикации:

```sh
npm run build
npm run preview
```

Для запуска нужен Node.js 20.19+ или 22.12+. При сборке файлы страницы копируются без изменений. Это сохраняет AMP-разметку и позволяет сравнивать исходные файлы в заданиях на производительность. Замеры лучше запускать через `preview`: в режиме `dev` Vite добавляет на страницу свой служебный скрипт.

## Условия заданий

Ниже — условия заданий. Файлы из `addons/...` находятся в исходном учебном комплекте.

### Задание №7

```text
Разработать javascript-конвертер из xml в json. Визуально в окне браузера должна быть форма с полями для ввода xml- и вывода json-данных, кнопка "конвертировать". Пользователь должен ввести в поле для xml код любого xml-совместимого документа. При нажатии на кнопку "конвертировать" должна быть осуществлена конвертация этих данных в формат json, результат конвертации должен отобразиться в соответствующем поле.

Не допускается использование внешних библиотек и фреймворков, функция конвертации должна быть написана самостоятельно.
```
